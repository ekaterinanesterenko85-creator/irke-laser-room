# План: сайт-визитка кабинета лазерной эпиляции «Ирке LaserRoom»

## Цель
Создать одностраничный сайт-визитку для мастера лазерной эпиляции Ирке Масловой в Саратове. Сайт должен приводить клиенток к записи через мессенджеры, показывать актуальный прайс и укреплять доверие к мастеру.

## Структура и содержание страницы

### 1. Hero / первый экран
- Название: «Ирке LaserRoom».
- Подзаголовок: лазерная эпиляция для женщин в центре Саратова.
- Главный оффер: «Подмышки за 500 ₽ при первом посещении» (обычная цена 900 ₽).
- Блок быстрой записи: кнопки WhatsApp, Telegram, VK с готовым текстом «Здравствуйте, хочу записаться на...».
- Мягкий призыв: «Запишитесь удобным способом — отвечу за 5–10 минут, если не в процедуре».

### 2. Услуги и цены
Два табличных/карточных блока.

**Отдельные зоны**
- Подмышечные впадины — 900 ₽
- Руки до локтя — 900 ₽
- Руки выше локтя — 900 ₽
- Руки полностью — 1 700 ₽
- Классическое бикини — 1 000 ₽
- Глубокое бикини — 1 200 ₽
- Тотальное бикини — 1 400 ₽
- Голени — 1 200 ₽
- Бёдра — 1 200 ₽
- Ноги полностью — 2 200 ₽
- Мини зоны — 400 ₽

**Комплексы**
- Мини — тотальное бикини + подмышки — 2 200 ₽
- Миди — голени + тотальное бикини + подмышки — 3 200 ₽

- Макси — ноги полностью + тотальное бикини + руки полностью + подмышки — 4 900 ₽

Каждый пункт с кнопкой «Записаться на эту зону».

### 3. Акция для новых клиентов
- Карточка акции «Гладкие подмышки».
- Условия: 500 ₽ вместо 900 ₽ при первом посещении, один раз, один месяц с даты запуска.
- Формулировка без слова «скидка 50%» — только конкретная цена.
- Кнопка «Хочу на подмышки по акции».

### 4. О мастере
- Имя: Ирке Маслова.
- Ключевые факты: работа с июня 2023, обучение лазерной эпиляции, собственный аппарат, индивидуальный подбор параметров.
- Образ: сильный специалист без холодности, «свой человек», к которому можно задать неловкий вопрос.
- Тон: дружеский, экспертный, без пафоса и обещаний чуда.

### 5. Почему выбирают
4 коротких преимущества:
1. Тщательная проработка зон и внимание к реакции кожи.
2. Индивидуальный подбор параметров под тип кожи и волос.
3. Комфортная процедура: охлаждение, паузы по запросу, доброжелательное общение.
4. Удобное расположение в центре Саратова, приём с 09:00 до 21:00.

### 6. Как проходит визит
3–4 шага:
1. Запись в мессенджере — уточняем зоны, опыт и противопоказания.
2. В кабинете — консультация, заполнение карточки, подбор режима.
3. Процедура — охлаждение кожи, щадящая обработка, комфортная атмосфера.
4. После — памятка по уходу и план следующих визитов.

## Техническая реализация

- **Фреймворк:** TanStack Start v1, одностраничный лендинг на `/` (переписать `src/routes/index.tsx`).
- **Стили:** Tailwind CSS v4, семантические токены из `src/styles.css`.
- **Компоненты:** shadcn/ui — Button, Card, Accordion (для FAQ/памятки), Sheet (для мобильного меню).
- **Форма записи:** не отправляет данные на сервер, а открывает мессенджер по deep link с предзаполненным текстом. Кнопки для WhatsApp, Telegram, VK.
- **Изображения:** сгенерировать hero-иллюстрацию/фото в мягком женственном стиле; если у мастера есть фото кабинета — использовать его.
- **SEO:** уникальный `head()` для `/` с title, description, og:title, og:description, og:type, twitter:card.
- **Адаптив:** mobile-first, breakpoints Tailwind.

## Дизайн-направление
Тёплый, уютный, женственный, но профессиональный интерфейс. Мягкая пастельная палитра (персиковый/розовый акцент на нейтральном светлом фоне), округлые формы, много воздуха, дружеский тон текста. Без холодного медицинского минимализма и без агрессивных продажных триггеров.
